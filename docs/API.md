# API 文档维护说明

## 文档作用

本文件用于记录 FastAPI 项目的接口使用约定、业务调用流程和接口版本策略。
具体的路径、参数、请求体和响应模型以代码生成的 OpenAPI 文档为准：

- Swagger UI：`/docs`
- ReDoc：`/redoc`
- OpenAPI Schema：`/openapi.json`

本文件不重复抄录每一个接口字段，重点补充自动文档无法完整表达的业务规则。

## 维护规则

- 新增或修改接口时，同时更新 FastAPI 路由、Pydantic 模型和本文件相关说明。
- 所有接口应设置清晰的 `summary`、`description`、响应模型和状态码。
- 破坏性变更必须说明影响范围、迁移方式和兼容期限。
- API 文档中的示例不得包含真实账号、Token、密钥或生产数据。
- 发布接口变更时，在 `changelog.md` 中同步记录。

## 通用约定

### 认证

说明 Token 获取方式、请求头格式、过期行为和无权限响应。例如：

```http
Authorization: Bearer <access_token>
```

### 通用响应

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

> 如果项目实际返回结构不同，应以项目实现为准，并在此处更新。

### 常用状态码

| 状态码 | 含义 | 使用场景 |
| --- | --- | --- |
| 200 | 成功 | 查询或更新成功 |
| 201 | 已创建 | 创建资源成功 |
| 400 | 请求错误 | 参数格式或业务参数不合法 |
| 401 | 未认证 | Token 缺失或无效 |
| 403 | 无权限 | 已认证但无访问权限 |
| 404 | 不存在 | 目标资源不存在 |
| 409 | 冲突 | 重复创建或状态冲突 |
| 422 | 参数校验失败 | FastAPI/Pydantic 校验失败 |
| 500 | 服务端错误 | 未预期的服务端异常 |

## 版本与兼容策略

- 当前版本：`v1`。

- 破坏性变更需要在 `changelog.md` 中记录，并通知所有调用方。
